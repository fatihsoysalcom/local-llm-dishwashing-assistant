# Local LLM Dishwashing Assistant

This Python script simulates a local LLM's decision-making process for optimizing dishwashing. It takes the number of used dishes as input and provides a simple, rule-based recommendation, mimicking how a local LLM might suggest a course of action.

## Language

`python`

## How to Run

Save the code as `dish_assistant.py` and run it from your terminal using `python dish_assistant.py`.
